## Webgis

Hasil penelitian disajikan melalui webgis interaktif yang memuat peta web interaktif yang menyajikan hasil analisis aksesibilitas dan kesesuaian lokasi fasilitas pendidikan jenjang SMA/sederajat pada tingkat desa. Peta memuat tiga lapisan analisis, yaitu aksesibilitas dengan metode E2SFCA, kesesuaian lahan untuk pembangunan sekolah baru, dan rekomendasi kebijakan lokasi SMA per desa. Pengguna dapat memfilter data berdasarkan kabupaten/kota, kecamatan, dan kategori, mencari wilayah tertentu, serta melihat rincian data dengan mengeklik wilayah pada peta yang dilengkapi pilihan citra satelit..

**Tautan web gis:** https://web-skripsi-very.vercel.app/
