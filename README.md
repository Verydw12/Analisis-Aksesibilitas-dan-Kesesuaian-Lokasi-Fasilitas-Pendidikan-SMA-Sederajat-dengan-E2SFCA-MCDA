## Deskripsi Singkat
Peta web interaktif yang menyajikan tiga hasil analisis spasial pada tingkat desa:
1. **Aksesibilitas (E2SFCA)**: indeks jangkauan layanan SMA/sederajat.
2. **Kesesuaian Lahan (MCDA)**: kelayakan lokasi pembangunan sekolah baru.
3. **Kebijakan Lokasi SMA**: rekomendasi kebijakan per desa.
